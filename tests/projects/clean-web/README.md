# PhraseBox

A language practice web app: flashcards, a chat partner and shared study decks.
Built with Next.js and Supabase.

## Run locally

    npm install
    npm run dev

Secrets (`SUPABASE_SERVICE_KEY`, `STRIPE_SECRET_KEY`, `OPENAI_API_KEY`, `SESSION_SECRET`, `UPSTASH_REDIS_REST_TOKEN`) come from the environment, never from code.
